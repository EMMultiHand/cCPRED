# Cyberpunk RED — локальная копия (тёмно-коричневая тема)

Локальная офлайн-копия двух сайтов:

| Раздел | Оригинал | Что это |
|---|---|---|
| `app/` | **redcharacters.com** | Приложение «Cyberpunk RED Character App» — создание и ведение листов персонажей (Flutter/CanvasKit сборка) |
| `data-pool/` | **alec-leon.github.io/data-pool** | «ДатаПул» — русский справочник по Cyberpunk RED/207x (снаряжение, хром, противники, ширма мастера, генераторы, книги правил и т.д.) |

Оба сайта переоформлены в **тёмно-коричневой теме** (глубокий кофейный фон, медные акценты, пергаментный текст),
а справочник ДатаПул встроен прямо в приложение — плиткой **«ДАТАПУЛ»** на вкладке «Агент».

---

## Запуск

Нужен локальный веб-сервер (приложение использует WebAssembly/шрифты и данные — из `file://` не работает).

**Способ 1 (Windows):** запустите `start.cmd` — сервер поднимется на `http://localhost:8000/`,
откроется браузер, а в окне будут напечатаны адреса для телефона в той же сети (Wi-Fi).
Если рядом лежит папка `certs/`, сервер сразу поднимает и **https на порту 8443** —
это адрес для установки приложения на телефон.

**Способ 2 (вручную):** в папке с копией выполните

```
node tools\serve.js . 8000
```

либо любой другой статический сервер, например `python -m http.server 8000 --bind 0.0.0.0`.

**Важно:** раздавать нужно корень этой папки (там, где лежат `index.html`, `app/`, `data-pool/`).
Внутренние ссылки относительные, поэтому копия работает и из подпапки — именно так она
опубликована на GitHub Pages.

## Установка на телефон (как приложение)

Android устанавливает сайты как приложения (PWA) только по **https**. Есть два пути: онлайн
(проще всего) и полностью локальный, без интернета.

### Способ 1 (рекомендуется): онлайн-версия на GitHub Pages

Копия опубликована здесь: **https://emmultihand.github.io/cCPRED/**

На телефоне откройте

```
https://emmultihand.github.io/cCPRED/app/
```

и выберите в меню Chrome «⋮» → **«Установить приложение»**. Сертификаты не нужны — это обычный
https-адрес. После первой загрузки приложение кэшируется service worker’ом и **работает офлайн**;
листы персонажей хранятся в памяти браузера телефона. Персонажи привязаны к адресу (origin)
`emmultihand.github.io` — для страховки делайте экспорт листа (кнопка экспорта в приложении).

Сам репозиторий: **github.com/EMMultiHand/cCPRED** (при обновлении файлов Pages пересобирается
автоматически за 1–2 минуты).

### Способ 2 (офлайн, без интернета): свой сертификат

Если интернета нет вовсе — поднимите сервер на компьютере (`start.cmd`) и установите приложение
по локальному https с самодельным сертификатом (см. ниже).

#### Шаг 1. Установите сертификат на телефон

На телефоне (в той же Wi-Fi сети) откройте:

```
http://IP-компьютера:8000/certs/rootCA.crt
```

(IP-адрес печатает `start.cmd`, например `192.168.0.180`) — файл скачается.

- **Android:** Настройки → Безопасность → Шифрование и учётные данные → **Установить
  сертификат** → **Сертификат ЦС** → выберите скачанный `rootCA.crt` → «Установить всё равно».
  (Путь в настройках немного отличается на разных моделях — ищите «Установить сертификат»
  в разделе безопасности.)
- **iPhone (Safari):** после скачивания появится «Профиль загружен» → Настройки → Основные →
  **VPN и управление устройством** → установите профиль (потребуется код-пароль).
  Затем: Настройки → Основные → **Об этом устройстве** → Доверие сертификатам →
  включите полное доверие для «mkcert …».

Сертификат самодельный (создан утилитой mkcert на вашем компьютере), действует до 2029 года
и используется только в локальной сети.

#### Шаг 2. Откройте приложение и установите его

На телефоне откройте:

```
https://IP-компьютера:8443/app/
```

- **Android (Chrome):** убедитесь, что в адресной строке «замок»; меню «⋮» →
  **«Установить приложение»** (может называться «Добавить на главный экран» → «Установить»).
- **iPhone (Safari):** «Поделиться» (квадрат со стрелкой) → **«На экран “Домой”»**.

Готово: на главном экране появится «Киберпанк RED». После первой загрузки приложение
кэшируется service worker’ом и **продолжает работать без компьютера и интернета**;
листы персонажей хранятся в памяти браузера телефона.

Если значка установки не появилось:

- проверьте, что открыт именно `https://…:8443/app/` и в адресной строке замок;
- на Android после установки сертификата полностью закройте Chrome (смахните из недавних)
  и откройте заново;
- если раньше открывали этот адрес и видели предупреждение о сертификате — удалите данные сайта
  (меню «⋮» → «Настройки сайта» → «Удалить данные») и зайдите заново.

Нюансы:

- Сервер должен быть запущен на компьютере (`start.cmd`), телефон — в той же Wi-Fi сети.
  Интернет для всего этого не нужен.
- Персонажи привязаны к адресу открытия (хранилище браузера). Заводите их в установленном
  приложении — его адрес `https://IP:8443/app/` не меняется.
- IP-адрес компьютера может меняться (DHCP). Если приложение вдруг «перестало открываться»,
  сверьте адрес в окне `start.cmd`; в роутере можно закрепить IP за компьютером.

### Альтернатива: https-туннель (интернет, без установки сертификата)

Если нужен доступ не из дома или не хочется ставить сертификат: запустите `tunnel.cmd`
(при запущенном `start.cmd`) — он напечатает адрес вида `https://xxxxxxxx.tunnelmole.net`.
Откройте на телефоне `https://xxxxxxxx.tunnelmole.net/app/` и установите приложение.
Адрес бесплатного туннеля **меняется при каждом запуске** (свежий пишется в `tools\tunnel.log`),
а сам туннель живёт, пока открыто его окно. Для постоянного пользования лучше локальный https
из шага 1.

## Что внутри

```
index.html            — стартовая страница-лаунчер (тёмно-коричневая тема)
start.cmd             — запуск сервера и браузера (+ адреса для телефона)
tunnel.cmd            — https-туннель для установки приложения на телефон
app/                  — приложение «Cyberpunk RED Character App»
  index.html          — оболочка: загрузчик в теме, встроенная секция «ДатаПул», регистрация service worker
  main.dart.js        — приложение (палитра перекрашена в тёмно-коричневую)
  flutter_bootstrap.js— загрузчик (локальный CanvasKit)
  flutter_service_worker.js — офлайн-кэш (собран tools/build_sw.js)
  manifest.json       — манифест PWA (имя «Киберпанк RED», тёмные цвета)
  canvaskit/          — движок рендеринга (основной и chromium-вариант)
  assets/             — шрифты, изображения ролей, иконки, флаги
data-pool/            — справочник «ДатаПул» (все страницы + изображения, ~170 МБ)
  vendor/lunr/        — локальная копия поискового движка lunr (офлайн-поиск)
  search-index.json   — индекс поиска
  data/               — данные противников, цен и т.д.
certs/                — самодельный сертификат для локального https (rootCA.crt — ставится на телефон)
tools/                — скрипты, которыми собиралась и перекрашивалась копия
```

## Как сделана копия (tools/)

| Скрипт | Назначение |
|---|---|
| `mirror_app.py` | Скачивает сборку redcharacters.com (HTML, JS, assets, CanvasKit с gstatic) |
| `patch_app_theme.py` | Перекрашивает палитру приложения в `main.dart.js`, подключает локальный CanvasKit, добавляет панель «ДатаПул» и форс тёмной темы. Идемпотентен |
| `patch_app_catalog.py` | Дополняет каталог приложения данными ДатаПула (оружие, броня, импланты, снаряжение, боеприпасы, корпорации). Идемпотентен, ведёт реестр `catalog_ledger.json` |
| `patch_custom_implants.py` | Добавляет в диалог каждой зоны имплантов кнопку «Создать имплант» с формой (название, категория, ячейки, цена, ПЧ, установка, эффект, описание), шестерёнку на карточках своих имплантов с настройками («Редактировать»/«Удалить»). Свои импланты сохраняются в `localStorage` (`cpref_custom_implants`), сразу устанавливаются в зону и переживают перезагрузку. Идемпотентен |
| `patch_agent_datapool.py` | Добавляет во вкладку «Агент» плитку «Датапул» сразу после «Фракций» (иконка и список вкладок). Идемпотентен |
| `patch_inline_datapool.py` | Превращает плитку «Датапул» в обычную секцию: ДатаПул занимает область под сеткой вкладок, скрывается при смене вкладки/страницы и при диалогах, сохраняет открытую страницу. Идемпотентен |
| `build_dp_additions.py` | Собирает дополнения каталога из зеркала ДатаПула в `dp_additions.json` |
| `mirror_datapool.py` | Скачивает справочник ДатаПул (страницы, CSS/JS, изображения), вендорит lunr |
| `patch_datapool_theme.py` | Перекрашивает CSS/HTML справочника (включая альфу 8-значных hex) |
| `patch_datapool_images.py` | Перекрашивает «свои» бренд-картинки сайта (шапка, логотип, favicon): красные тона → медные |
| `check_datapool_links.py` | Проверяет целостность зеркала справочника: все локальные ссылки/ресурсы на месте |
| `serve.js` | Node-сервер с keep-alive и корректными `Content-Length`: http на порту 8000 и https на 8443 (автоматически, если есть `certs/`) |
| `build_sw.js` | Собирает офлайн service worker `app/flutter_service_worker.js` (запускать после изменения файлов `app/`) |
| `mkcert.exe` | Утилита, которой создан локальный сертификат для https (файлы в `certs/`, действуют до 2029 года) |
| `fix_cmd_encoding.py` | Перекодирует `.cmd`-файлы в CP866 + CRLF, чтобы русский текст правильно отображался в консоли Windows |
| `relativize_paths.py` | Переводит абсолютные ссылки справочника в относительные и делает `__BASE_PATH__` самовычисляемым (чтобы копия работала из подпапки, как на GitHub Pages) |
| `push_chunks.py` | Резервная отправка репозитория на GitHub маленькими порциями (если полный `git push` не проходит по таймауту на медленном канале) |
| `tunnel-run.cmd` | Служебный запуск туннеля отдельным процессом (лог пишется в `tools/tunnel.log`) |

Если после обновления страница выглядит устаревшей (старые цвета/картинки), обновите её
жёстко: **Ctrl+F5** (приложение кэширует ресурсы через service worker).

## Чем копия отличается от оригиналов

- **Тема.** Приложение: цвета палитры заданы в коде `main.dart.js` (CanvasKit рисует на canvas, CSS не влияет) —
  поэтому палитра аккуратно заменена в самом коде; тёмный режим принудительно включается через
  `localStorage['flutter.app_theme_mode'] = '"dark"'` ещё до старта приложения.
  Справочник: цвета перекрашены в CSS и в инлайн-стилях HTML.
- **ДатаПул в «Агенте».** На вкладке **«Агент»** седьмая плитка «ДАТАПУЛ» стоит сразу после
  «Фракций» и ведёт себя как остальные вкладки: под сеткой открывается секция с самим
  справочником (iframe на `../data-pool/`). Плавающей кнопки и боковой панели больше нет.
  Iframe загружается один раз и сохраняет открытую страницу при переключении вкладок;
  его позиция вычисляется по геометрии приложения (семантика Flutter), следует за
  окном/поворотом экрана и временно скрывается, пока открыт диалог приложения.
- **Офлайн.** CanvasKit и lunr скачаны локально; внешние CDN не используются. Приложение
  после первой загрузки кэшируется service worker’ом (`app/flutter_service_worker.js`) —
  работает без сети; установленное на телефон приложение открывается полностью офлайн.
- **Свои импланты.** В каждой зоне имплантов (нейросистема, оптика, аудио, голова, руки, корпус, ноги, стиль)
  есть кнопка «Создать имплант» — как создание оружия и брони. Свой имплант задаётся формой
  (название, категория, число ячеек, цена, ПЧ, установка, эффект, описание), сразу устанавливается
  в текущую зону и сохраняется в `localStorage` (`cpref_custom_implants`), поэтому остаётся
  в каталоге после перезагрузки. Повторное создание с тем же названием обновляет запись.
  На карточке своего импланта в списке зоны есть шестерёнка (как у оружия и брони):
  «Редактировать» открывает ту же форму с заполненными полями (переименование обновляет
  название во всех зонах персонажа), «Удалить» убирает имплант из каталога, `localStorage`
  и из всех зон.
- **Переносимость.** Все внутренние ссылки копии относительные, а базовый путь справочника
  (`window.__BASE_PATH__`) вычисляется на лету — поэтому одна и та же копия работает и из корня
  локального сервера, и из подпапки на GitHub Pages (`/cCPRED/…`).
- **Не изменялись:** иллюстрации в `data-pool/images/content/**` и логотипы сторонних брендов
  (R. Talsorian Games, CD Projekt RED) — они оставлены в оригинальном виде.
